# موقع الشيخ محمد أحمد الهادي الكرار

واجهة عربية متجاوبة لمكتبة الشيخ محمد أحمد الهادي الكرار العلمية والصوتية، مبنية
باستخدام HTML5 وCSS3 وJavaScript خالص دون أطر خارجية.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## 📌 نظرة عامة
يوفّر الموقع أرشيفًا منظمًا للمحاضرات الصوتية والمقالات المكتوبة والكتب بصيغة PDF،
مع صفحة مستقلة للتعريف بالشيخ، وبحث وتصنيف، وصفحة تفاصيل لكل مادة.

تم بناء هذا المستودع لتطوير الواجهة الأمامية (Frontend) الخاصة بالنظام وفق وثيقة المتطلبات
(SRS) في المجلد `docs/`، باستخدام HTML5 الدلالي، وCSS3 حديث (Flexbox/Grid + متغيرات)،
وجافاسكريبت خالص (Vanilla ES6+) دون أي أطر خارجية، مع التحقق من قابلية الوصول (WCAG 2.2 AA)
وممارسات تحسين محركات البحث (SEO).

## ✨ الميزات الأساسية
- **دعم كامل للغة العربية:** واجهة مصممة لدعم اتجاه اليمين إلى اليسار (RTL) بخط ZAIN.
- **تصميم متجاوب (Responsive):** واجهة تتكيف مع الأجهزة المحمولة وأجهزة سطح المكتب.
- **مشغّل صوتيات موحّد:** مشغّل واحد يعمل عبر البطاقات وصفحة التفاصيل (يتوقف تلقائيًا عند تشغيل ملف آخر)،
  مع تحكم بالصوت والسرعة وشريط التقدم.
- **المقالات والكتب:** عرض المقالات داخل الصفحة، وقراءة ملفات PDF داخل قارئ مدمج مع زر تنزيل مباشر.
- **صفحة حول الشيخ:** صفحة مستقلة تحتوي صورة الشيخ ونبذة تعريفية عنه، ولا تعرض النبذة في الصفحة الرئيسية.
- **إحصاءات مباشرة:** إجمالي المواد والملفات الصوتية والمقالات والكتب والتصنيفات، محسوبة من المواد المنشورة.
- **نظام بحث وتصفح:** بحث فوري في العنوان/الوصف/المؤلف/الكلمات المفتاحية مع تصفية بالتصنيف
  والوسيط والفرز، وروابط URL قابلة للمشاركة.
- **لوحة تحكم (محاكاة):** إدارة المواد والتصنيفات والمستخدمين، وسجل عمليات، وأدوار
  (مدير نظام / مدير محتوى) مع فصل الصلاحيات (RBAC).
- **التحقق من المدخلات والأمان:** سياسة كلمات مرور قوية، قفل الحساب بعد محاولات فاشلة،
  ترميز المخرجات لمنع XSS، والتحقق من صيغة وحجم الملف الصوتي (≤100MB: MP3/WAV/OGG/M4A).
- **سهولة الوصول (Accessibility):** سمات ARIA، تركيز مرئي، تنقل بلوحة المفاتيح،
  ودعم تفضيل تقليل الحركة.

## 🚀 التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً بسيطاً:

```bash
# Python 3
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

الصفحات الأساسية:

| الصفحة | المسار |
| --- | --- |
| الرئيسية | `index.html` |
| البحث والتصفح | `pages/search.html` |
| حول الشيخ | `pages/about.html` |
| تفاصيل مادة | `pages/content-detail.html?id=<content-id>` |
| لوحة الإدارة | `pages/dashboard.html` |

## 📂 هيكل المشروع
```text
DSACMS/
├── docs/                        # وثيقة متطلبات المشروع (SRS)
├── assets/
│   ├── css/style.css            # التنسيقات العامة + الخطوط والمتغيرات
│   ├── js/main.js               # كامل منطق النظام (بيانات تجريبية + طبقة تخزين)
│   ├── images/                  # شعار الموقع وصورة الشيخ المؤقتة
│   ├── audio/                   # ملفات صوتية تجريبية (track-1..6.wav)
│   └── font/                    # خط ZAIN
├── pages/
│   ├── search.html              # البحث والتصفية
│   ├── content-detail.html      # تفاصيل المادة والمشغّل الصوتي
│   ├── about.html               # حول الشيخ محمد أحمد الهادي الكرار
│   ├── login.html               # تسجيل الدخول (بقفل المحاولات)
│   └── dashboard.html           # لوحة التحكم (أدوار/تسجيل عمليات)
├── index.html                   # الصفحة الرئيسية
├── robots.txt                   # إرشادات محركات البحث
├── sitemap.xml                  # خريطة الموقع (استبدل نطاق المثال قبل النشر)
└── README.md
```

## 🗄️ التخزين
تُحفَظ البيانات في `localStorage` بمفاتيح: `dsacms_contents`، `dsacms_categories`،
`dsacms_users`، `dsacms_session`، `dsacms_audit`، `dsacms_lockout`. هذه المحاكاة
مصمّمة بطبقة تخزين `store` قابلة للاستبدال بواجهة API حقيقية لاحقاً.

> ملاحظة: قبل النشر، استبدل النطاق التجريبي `https://dsacms.example/` المستخدم في
> `sitemap.xml` و`robots.txt` ووسوم canonical بنطاق الموقع الفعلي.

## 🖼️ استبدال صورة الشيخ

الصورة الحالية في `assets/images/sheikh-placeholder.svg` صورة مؤقتة للتصميم. لاستبدالها
بصورة حقيقية، حدّث مسار `src` للصورة في `pages/about.html` مع الحفاظ على النص البديل
المناسب لإمكانية الوصول.

## ✅ التحقق

تم التحقق من المشروع باستخدام:

```bash
node --check assets/js/main.js
git diff --check
```

كما تم اختبار صفحة المقال وصفحة الكتاب PDF عبر خادم محلي، بما في ذلك ظهور قارئ PDF
وزر التنزيل، وظهور إحصاءات المقالات والكتب في الصفحة الرئيسية.
