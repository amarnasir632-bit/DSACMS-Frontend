## 📌 نظرة عامة
نظام **DSACMS** هو نظام ويب مخصص لإدارة وتنظيم وإتاحة المحتوى العلمي. يركز الإصدار الأول من هذا النظام بشكل أساسي على المحتوى الصوتي (Audio-first) والمواد العلمية القابلة للبحث والتصفح.

تم بناء هذا المستودع لتطوير الواجهة الأمامية (Frontend) الخاصة بالنظام، لضمان تجربة مستخدم بسيطة، واضحة، ومناسبة لجميع الفئات التقنية[cite: 1].

## ✨ الميزات الأساسية
- **دعم كامل للغة العربية:** واجهة مصممة لدعم اتجاه اليمين إلى اليسار (RTL)[cite: 1].
- **تصميم متجاوب (Responsive):** واجهة تتكيف مع الأجهزة المحمولة وأجهزة سطح المكتب[cite: 1].
- **مشغل صوتيات مدمج:** تشغيل الملفات الصوتية المرتبطة بالمواد العلمية والتحكم بها[cite: 1].
- **نظام بحث وتصفح:** وظيفة بحث للعثور على المواد العلمية وتصفحها عبر التصنيفات[cite: 1].
- **سهولة الوصول (Accessibility):** مراعاة إمكانية الوصول لتكون مناسبة لكبار السن وضعاف البصر[cite: 1].
